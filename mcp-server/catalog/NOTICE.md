# Third-party data in the catalog

## KiCad libraries (`imported_parts.json`)

`imported_parts.json` is generated by `scripts/import_kicad.py` from the official KiCad symbol and footprint
libraries (`kicad-symbols`, `kicad-footprints`): pin numbers, pin names, pin electrical types, descriptions,
keywords, datasheet links and pad geometry are taken or derived from that data.

  Every imported part records its source symbol, footprint and library version in its `import` field.
* **Designs are not affected.** Under the KiCad exception, a board, netlist or Gerber files you generate with these
  parts need not carry the CC-BY-SA terms or attribution.
* **Redistributing `imported_parts.json` is affected.** It is a modified collection of the library data, so a copy

* The footprints are re-expressed in a simplified form (pads and an outline rectangle) and are unreviewed.

## Supplier data (`sourcing.json`)

LCSC part numbers, list prices (USD, quantity-1 tier), stock and library type were read from the public
[jlcparts](https://github.com/yaqwsx/jlcparts) database (code MIT: [`licenses/jlcparts-MIT.txt`](licenses/jlcparts-MIT.txt)),
which mirrors JLCPCB's component library. `sourcing.json` records the database date in `_meta.data_date`.
Prices and stock change constantly: treat them as estimates, not quotes, and regenerate with
`scripts/refresh_sourcing.py`. Part numbers, manufacturer names and prices are factual data; product names
belong to their owners.
